Executive Summary

This document summarizes the recent round of development work delivered on the Red Sands Pain Management website. Work covered six areas: a new Team page (the largest item), navigation and footer redesign, the addition of fax contact information, photo management, and several UX bug fixes. All changes were tested in development and are ready for production deployment.

3. Team Page (New Feature)

Estimated effort: 6.75 hours

A new Team page was designed and implemented from scratch, with a complementary preview section on the home page. The page supports three categories of people: Administrative Team, Clinical Team, and Our Collaborations.

Data architecture (0.75 h)

  • Designed a typed, reusable data structure for team members.
  • Centralized all 11 team-member entries (name, title, photo, bio, business, contact) in a single module so future updates require editing only one file.
  • Generated URL-safe slugs for each member to support deep linking from anywhere on the site.

Home page Team section (carousel) (1.5 h)

  • Initial 3-section grid layout was prototyped, then revised based on feedback.
  • Final design: a horizontal scrolling carousel showing all 11 members in one row.
  • Snap-scroll with drag-free behavior; navigation arrows appear on desktop.
  • Responsive sizing: 2 cards on mobile, 3 on small tablets, 4 on large tablets, 5 on desktop.
  • Each card displays photo, name, title, and a category badge (Admin / Clinical / Collaborator).

Full /team page (3.0 h)

  • Created a standalone route at /team with hero, three labeled sections, and footer.
  • Initial implementation used a full-width row layout per member.
  • Redesigned based on feedback to a modern compact-grid + click-to-expand pattern.
  • Subtle fade-in scroll animations using IntersectionObserver (no heavy animation libraries).
  • Photo zoom and ring-color shift on card hover for a polished feel.
  • Bios collapse and expand inline with smooth height animation.
  • Collaborator cards expand to reveal Website / Phone / Email action buttons.
  • Fully accessible: aria-expanded states, keyboard focus rings, disabled state for cards without bios.

Navigation integration (0.25 h)

  • Added “Team” as a top-level link in the desktop navigation.
  • Added “Team” to the mobile navigation menu.
  • Added “Team” link to the footer’s Quick Links column.

Cross-linking & deep linking (1.0 h)

  • Each card on the home carousel is now clickable, linking to the matching person on /team.
  • URL hash routing (e.g., /team#dr-kamran-khan) auto-scrolls to the right card.
  • Target card is visually highlighted (maroon border + soft ring) on arrival.
  • Target member’s bio is pre-expanded so the user sees the information immediately.
  • Smooth scroll with offset for the sticky navigation bar.

Section ordering (0.25 h)

  • Reordered the carousel sequence to Admin team first, then Clinical, then Collaborators to match the natural organizational flow.

4. Photo Management

Estimated effort: 1.25 hours

Wired and refined team photographs (1.25 h)

  • Imported 8 team photographs from the supplied folder.
  • URL-encoded image paths for filenames containing spaces and special characters.
  • Implemented “object-top” image positioning so faces remain visible inside circular avatars (previously, the default center-crop was cutting off the top of some heads).
  • Added initials-fallback avatars (e.g., “CN” for Cathy Nabuurs) for team members without a supplied photo, with consistent styling.
  • Updated Maria Khan’s photograph to the newly supplied file.
  • Updated Katie Beck’s photograph to the newly supplied (smaller, web-optimized) file.
  • Resolved a folder case-sensitivity issue (“Team” renamed to “team”) that would have broken photo loading once deployed to the Linux production server.

5. Footer Redesign

Estimated effort: 1.25 hours

Removed social media column (0.25 h)

  • Removed the “Connect With Us” section per client request.

6. UX Bug Fixes & Improvements

Estimated effort: 1.5 hours

Scroll position reset on route change (0.5 h)

  • Created a dedicated route-change handler component.
  • Resolved the issue where clicking “View Full Team” (or other internal links) would land the user at the same scroll offset on the new page instead of the top.
  • Preserves intentional in-page anchor behavior (e.g., /#about still scrolls to the section).

Hash anchor scrolling fixes (0.75 h)

  • Fixed the footer “About” and “Covered Services” links that were not scrolling to their target sections after navigation.
  • Added retry logic so the scroll waits for React to render the section before attempting to scroll (covers cross-page navigation).
  • Added a CSS scroll-margin offset so section headings are no longer hidden behind the sticky navigation bar when scrolled into view.

Photo cropping fix (0.25 h)

  • Resolved an issue where some portrait photos were being cropped at the top, cutting off the subject’s head.
  • Applied “object-top” anchoring across all team avatars on both the home carousel and the /team page.
